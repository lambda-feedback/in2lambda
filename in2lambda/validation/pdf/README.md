# PDF generator template

`template.latex` is a verbatim copy of `src/template.latex` from
https://github.com/lambda-feedback/pdf-generator at commit f1ebdd2, the pandoc template
Lambda Feedback renders question PDFs with. It is here so that in2lambda can compile a set
the way the platform does. Update it by copying the file again and changing the commit
here; do not edit it in place.
