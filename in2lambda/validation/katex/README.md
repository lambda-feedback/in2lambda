# KaTeX, as shipped

`katex.min.js` is `dist/katex.min.js` from the katex npm package, version 0.18.7, copied verbatim,
with KaTeX's own `LICENSE` beside it. `check.js` is ours and renders with it.

To move to a newer version: download the tarball (`npm pack katex@<version>`), copy `dist/katex.min.js`
and `LICENSE` out of it over these two, and change the version named above.
